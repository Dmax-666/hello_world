# Hello World Programs

This repository contains simple "Hello, World!" programs implemented in both C and C++.

## Files

- `hello_world.c` – A C program that prints "Hello, World!" to standard output.
- `hello_world.cpp` – A C++ program that prints "Hello, World!" to standard output.

## Building and Running

### C Version

```bash
gcc hello_world.c -o hello_world_c
./hello_world_c
```

### C++ Version

```bash
g++ hello_world.cpp -o hello_world_cpp
./hello_world_cpp
```
